# GBase 運用バックエンド デモ（厚生労働省 雇用保険 生成AIチャットボット）

厚生労働省 雇用保険 生成AIチャットボット案件の「運用バックエンド」の設計案を、静的な単一ページで触れるようにしたプロトタイプです。
要件分解 v0.3（OPS-R01〜R16／OPS-F01〜F30）のメニュー対応に沿って、8 つのメニューと各タブを日本語で再現しています。

- 何を見せるものか：プロンプト・モデル・検索パラメータの「下書き→評価→承認→リリース→実効設定の照合」、夜間バッチの状況と再実行、個人情報検知サービスの指標とモデル管理、利用量・コスト・API 利用上限、アクセス制御（参照のみ／設定編集／リリース責任者／運用操作／管理者）、運用操作記録（CSV 出力）、実効設定・テスト用スイッチの照合。
- 動かし方：`index.html` をブラウザで直接開くだけで動きます（ビルド不要・依存なし）。
- 客先向け表示：URL の末尾に `?view=customer` を付けると、SaaS 共用プレビューなど SaaS 製品向けの項目（デプロイ形態の切り替え、AWS クラウドイベント、データソースと接続状況）を非表示にし、客先専用デプロイの表示だけになります。TCI／厚生労働省への説明時に使います。
- データについて：画面上の数値・ボット名・アカウント・アラートはすべて模擬データです。客先の AWS、ログイン基盤、モデル API、精度検証プラットフォームには接続していません。操作内容はブラウザ内のみに保持し、再読み込みで初期化されます。
- 用語：運用バックエンド（本デモ）／管理画面（客先側）／精度検証プラットフォーム／個人情報検知サービス／運用操作記録（本デモの監査ログ）。

## 機能

- 稼働サマリとデータの取得元、取得データが古い／読み取り権限なしの状態表示。
- ボットとナレッジの参照、同期とアクセス範囲。
- プロンプト・パラメータの下書き、評価の関連付け、承認とリリース、インスタンスの実効設定の照合、ロールバック用の下書き。
- タスクの依存確認、記録付きの再実行、アラートの担当者対応、マスク済みログの検索。
- ボットの利用量、模擬の AWS コストと予算、API 利用上限の残り、ボット単位のコスト・応答速度、アクセス量・負荷監視（しきい値超過はアラートに連動）。
- 運用バックエンドの権限付与、操作権限マトリクス、ログイン方式の選択肢、運用操作記録と CSV 出力。
- セキュリティ設定：ログイン失敗ロック（回数・時間）の設定、実行環境の実効値との照合、ロック中アカウントの解除。
- モデルと検索：FAQ 採用しきい値・FAQ 質問文検索の有効／無効を下書き／評価のハッシュ値／リリース差分／履歴／ロールバックに含める。
- タスク実行：本案件の夜間バッチ（会話の仕分け・個人情報検知・FAQ 候補抽出・KPI 集計・13 か月保持期限クリーニング）の例。
- 個人情報検知サービス：指標パネル（稼働率・p95・503・要確認比率・種別ごとの検知件数・モデルバージョン）とモデル・規則バージョン、許可リスト、回帰検証の記録。
- システム接続の状態、実効設定・テスト用スイッチ（ConfigMap の読み取り専用）、デプロイ形態のプレビュー。

## 客先向け表示モード

URL に `?view=customer` を付けます。「SaaS 共用プレビュー・サンプルテナント」のデプロイ形態切り替え、「AWS クラウドイベント」タブ、「データソースと接続状況」タブを非表示にし、「客先専用デプロイ・ワークスペース」だけを残します。客先（TCI／厚生労働省）への説明時に使います。

## ローカルでの実行

ブラウザで `index.html` を直接開くか、次を実行します。

```bash
python3 -m http.server 8765
```

http://localhost:8765 を開きます。フロントエンドの依存関係のインストールは不要です。

## ソースの保守

- `index.html`：スタイルと JavaScript を含む単一ページ。単独で開けます。
- `governance.js`：JavaScript のソース（正本）。
- `sync-demo.py`：JS を編集した後に単一ページ HTML へ同期します。
- `vercel.json`：静的デプロイの設定と基本的な応答ヘッダー。

`governance.js` を変更したら `python3 sync-demo.py` を実行します。スタイルとページの外枠は `index.html` で保守します。

## Vercel へのデプロイ

```bash
vercel link --project gbase-ai-governance-demo
vercel deploy --prod
```

このリポジトリへの push は GitHub 自動デプロイを意味しません。現在の公開版は Vercel CLI でデプロイしています。

## デモの境界

すべてのデータは例であり、実際の AWS、客先のログイン基盤、モデル API、精度検証プラットフォームには接続していません。
状態は現在のページのメモリ内にのみ保持し、再読み込みで初期化されます。本番環境と検証環境は独立した模擬の状態を持ちます。
権限制御はプロトタイプの表示用で、正式なシステムではサーバー側の認証・認可が必要です。
SaaS 共用プレビューは文脈の再利用を議論するためのもので、マルチテナントの安全な分離が完成していることを意味しません。

## 検証

8 つのメニュー、評価とリリースのゲート、一部反映の照合、環境の分離、タスクの依存関係、ナレッジ参照の保持、アラート状態の分離、ロールごとの制限、客先向け表示での非表示タブを Playwright のスモークテストで確認しています。ページはスマートフォン、タブレット、デスクトップで表示できます。
